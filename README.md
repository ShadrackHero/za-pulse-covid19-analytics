# ZA Pulse — South Africa COVID-19 Provincial Analytics

10-day portfolio project: multi-source COVID-19 data for South African provinces,
loaded into a database, analysed in Python notebooks, and reported in Power BI with DAX.

## Status

Day 1 — repository created.

## Stack

- Python notebooks
- PostgreSQL (or MySQL)
- Power BI + DAX
- GitHub

## Data

Official provincial time series from
[dsfsi/covid19za](https://github.com/dsfsi/covid19za)
(Data Science for Social Impact, University of Pretoria).
Data licence: CC BY-SA 4.0.
